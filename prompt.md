Open-source проект под названием CursorFi — визуальный редактор сайтов в браузере, как Figma + Webflow, но с мгновенной двусторонней синхронизацией с локальными файлами проекта и глубокой интеграцией с Cursor IDE. Это должен быть лучший инструмент 2025-2026 годов для разработчиков, которые хотят собирать страницы визуально, но оставаться в чистом коде.

Цель: разработчик запускает одну команду, открывает браузер, перетаскивает блоки — и код в его проекте (Next.js, Vite, Astro и т.д.) меняется в реальном времени. И наоборот — меняет код в Cursor, видит изменения в браузере мгновенно.

Запускай всё внутри докер-контейнеров, по возможности избегай установки программ напрямую на сервер. Все примеры команд подразумевают запуск внутри временных или постоянных контейнеров.

Каждая фаза разработки должна проходить тесты.

Порты указаны для примера, выноси их в конфигурацию. Учти что проект будет запущен на удалённом сервере, а cursor IDE установлен на локальной Windows машине разработчика. 

Используй только самый современный стек 2025 года:

- TypeScript 5.6+
- Bun как пакетный менеджер и runtime
- Vite 6 + React 19 + React Compiler
- Tailwind CSS v4
- shadcn/ui + Radix UI + Lucide icons
- craft.js (последняя версия 2025 года) как основа canvas
- @dnd-kit для сложных drag-n-drop случаев
- chokidar для file watching
- TypeScript Compiler API + babel-traverse для парсинга и генерации кода
- Zustand для состояния
- tRPC + Elysia на бэкенде (Bun)
- Zod для всех схем
- Vitest + Playwright для тестов

ЭТАП 1 — Минимальный рабочий прототип (stages/01-basic)
Создай приложение, которое:
- Запускается командой bun dev
- Открывает браузер на http://localhost:5173
- Показывает пустой холст и 10 простых блоков слева (div, h1, button, card, image, input и т.д.)
- Можно перетаскивать блоки на холст
- При дропе в консоль выводится JSX-код этого блока
- Есть кнопка "Save to file" — сохраняет простой JSX в page.tsx
- Автоматические тесты (Vitest + Playwright): проверка, что после перетаскивания 3 блоков в файле появляется корректный JSX

ЭТАП 2 — Двусторонняя синхронизация (stages/02-sync)
Теперь самое важное. Реализуй полный цикл:
- При первом запуске спроси путь к существующему проекту (сохрани в cursorfi.json)
- Сделай парсер, который из любого .tsx файла создаёт дерево craft.js (ast → canvas state)
- Сделай генератор, который из дерева craft.js создаёт красивый, отформатированный код (canvas state → ast → code)
- При перетаскивании/ресайзе/изменении свойств — debounce 400 мс → генерируй код → пиши в реальный файл проекта
- Используй data-cf-id на каждом элементе для отслеживания
- При изменении файла на диске (chokidar) — парси новый AST → обновляй состояние craft.js → холст перерисовывается
- Тесты: Playwright скрипт, который перетаскивает блок, ждёт 1 сек, проверяет, что в файле изменились Tailwind-классы. Затем вручную меняет файл через fs.writeFile и проверяет, что элемент на холсте переместился.

ЭТАП 3 — Умные Tailwind-классы и позиционирование
- Реализуй преобразование позиций в правильные Tailwind-классы (translate-x/y, grid col-start/span, flex order и т.д.)
- Никогда не используй style={{}} и arbitrary values вроде top-[123px] — только семантические классы
- Поддержка absolute, relative, fixed, sticky
- Поддержка grid и flex с автоматическим расчётом
- Автоматическое определение, когда лучше использовать grid, а когда flex
- Тесты: 20 разных сценариев позиционирования с ожидаемым набором классов

ЭТАП 4 — Импорт своих компонентов и страниц
- При запуске сканируй src/components и src/app в целевом проекте
- Все .tsx компоненты автоматически появляются в левой панели как перетаскиваемые блоки
- Поддержка Next.js App Router и Pages Router, Vite, Astro
- Тесты: создай тестовый проект с 5 своими компонентами, проверь, что они появляются в UI

ЭТАП 5 — Интеграция с Cursor IDE
- Правый клик по элементу → "Open in Cursor" → открывает файл и строку через протокол cursor://file/...
- В README добавь инструкцию, как добавить команду в Cursor: "Open in CursorFi" → cursorfi://open?page=/about
- Реализуй простенький protocol handler (cursorfi:// протокол) через регистрацию в macOS/Windows

ЭТАП 6 — AI-чат внутри редактора
- В правой панели встроенный чат
- При выделении элемента отправляй в контекст: выбранный data-cf-id + текущий JSX + весь файл
- Заглушка: используй локальный API на http://localhost:3001/ai (просто возвращает изменённый код)
- Пример запросов:
  "сделай эту карточку с hover-эффектом как у Apple"
  "добавь анимацию появления снизу"
  "сделай адаптивной под мобильные"
  "переключи на dark mode"
- После ответа AI — автоматически применяй изменения через sync-слой

ЭТАП 7 — Финальная полировка
- 40+ красивых готовых блоков (Hero, Navbar, Pricing, Testimonials, FAQ, CTA, Footer и т.д.) — все с dark mode и адаптивностью
- Экспорт: кнопка "Deploy to Vercel" (через Vercel API)
- Красивый UI в стиле Figma 2025 + Linear
- Полная поддержка undo/redo (уже есть в craft.js)
- Авто-сохранение каждые 5 секунд
- MIT лицензия, красивый README с гифками и видео
- GitHub Actions: тесты + релиз на Bun registry

Важные нюансы, которые обязательно учти:
- Никогда не ломай существующий код — только добавляй/изменяй Tailwind-классы и props
- Всегда сохраняй пользовательский код внутри компонентов
- Если не можешь понять, где разместить элемент — используй relative + translate
- Поддержка нескольких страниц (app/page.tsx, app/about/page.tsx и т.д.)
- Работает с TypeScript, JSX, TSX
- Никаких .cursorfi.json внутри проекта пользователя — только один глобальный конфиг
- Полная совместимость с Cursor Composer — можно выделить элемент и нажать Cmd+K
